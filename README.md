# Demus Reborn

Prima demo PWA ispirata all'interfaccia di Demus.

## Cosa include
- Interfaccia responsive per iPhone/iPad
- Navigazione Aggiungi, Brani, Album, Artisti e Playlist
- Ricerca dimostrativa su un piccolo catalogo locale
- Salvataggio locale di brani e playlist
- Mini-player dimostrativo

## Limiti attuali
I brani sono dati di esempio: questa versione **non riproduce ancora musica reale** e non si collega a Spotify o YouTube. Le funzioni di riproduzione sono solo una simulazione dell'interfaccia.

## Pubblicazione
Carica i file nella root di un repository GitHub e abilita Settings → Pages → Deploy from a branch → main → /(root).
